# 逐行翻译 (LineTrans)

一款用于逐行 / 逐句对照翻译的安卓原生应用，基于 **Jetpack Compose** 开发。

## 功能

### 主界面 / 文档管理
- 顶部三横线侧边菜单：按文件夹分类展示已导入文本，并显示今日进度。
- 右上角 **+** 支持两种新建方式：导入 `.txt` 文件，或直接从剪贴板新建文档。
- 导入时可选择 **逐行 / 逐句** 切分方式；若文本中已存在「原文 ⇥ 译文」内容，可选择略过已有翻译。
- 顶部搜索框按名称筛选文档，另有 **全部 / 进行中 / 已完成** 过滤。
- 文档卡片展示进度百分比、完成句数、所属文件夹与最近更新时间；展开后可 **继续翻译 / 查看 / 导出 / 移动文件夹 / 重命名 / 删除**（删除有二次确认）。

### 翻译界面
- 支持 **逐句翻译** 与 **逐行翻译** 切换，切换时会尽量保留已有译文。
- 上方显示原文，下方输入译文，中间分隔线可调（20%–80%）、可锁定（防误触）。
- 原文可临时开启 **修改** 模式直接编辑。
- 译文区提供 **AI 翻译 / 跳过 / 复制**，更多菜单中有 **粘贴原文 / 清空译文 / 复制原文 / 重新翻译本句**。
- 顶部菜单提供 **跳转到…**（带完成状态的全文列表）、**跳到下一个未完成**、**批量翻译剩余内容**（可中途停止）。
- 「继续翻译」会直接定位到第一个未完成的句子。
- 打开设置后可开启 **翻译后自动跳转**，AI 翻译完一句自动进入下一句。
- 底部展示 **当前模型、调用次数、输入（未命中/命中）、输出、预计费用**。

### AI 翻译
- 支持 OpenAI 兼容接口、Anthropic、自定义接口，并可选择服务商预设地址。
- 在设置中添加 API 提供商与模型，可配置输入/输出价格（每百万 token）、高峰倍率、高峰时段、最大输出 tokens。
- 支持 **自动语言检测**，也可手动指定源语言 / 目标语言。
- 可配置 **前文参考条数**（0–10）与 **附加提示词**（术语、风格要求）。
- 请求失败（429 / 5xx / 网络异常）会自动重试，错误信息会直接显示在界面上。

### 导出
- 导入文本时选择一个用于存放数据的文件夹（源文本与译文都会保存在那里）。
- 导出方式一：仅导出已翻译文本。
- 导出方式二：已翻译文本替换源文本，未翻译文本显示为源文本。
- 导出对话框会显示每种方式的预览行数与首行内容。

### 局域网 Web 终端服务
- 在设置中开启 **Web 终端服务**，手机启动一个前台服务，监听局域网端口。
- 同一局域网内的电脑 / 手机浏览器打开：
  ```
  http://<手机IP>:<端口>/terminal
  ```
  即可使用基于 xterm.js 的 Web 终端，终端命令运行在手机本地 shell（`/system/bin/sh`）内。
- xterm.js 已打包进 `assets/web_terminal`，页面与资源全部离线可用。

## 技术栈
- Kotlin 1.9.24 / AGP 8.5.2 / Gradle 8.7
- Jetpack Compose (Material3) + Navigation Compose
- OkHttp + Gson（AI API 调用）
- NanoHTTPD + NanoWSD（局域网 Web / WebSocket 终端服务器）
- Android Storage Access Framework（文件夹选择与读写）

minSdk 26，targetSdk 34。

## 构建与运行
1. 使用 **Android Studio** 打开 `工程文件/LineTrans` 目录（本仓库根目录即项目目录）。
2. 首次打开时 Android Studio 会自动下载 Gradle 与依赖。
3. 连接安卓设备（或模拟器），点击 **Run** 即可；也可以在命令行执行：
   ```
   ./gradlew assembleDebug
   ```

命令行构建需要设置 `JAVA_HOME`（JDK 17 及以上）与 `ANDROID_HOME`（Android SDK 路径）。

## 说明
- 文档数据保存在应用私有目录（`files/docs/*.json`），写入经过防抖处理并放在 IO 线程，打字时不会卡顿。
- Web 终端运行在应用的本地 shell 中（非 root），仅具备应用进程的权限。
- 未配置模型价格时，界面只统计 token，不做费用估算。
